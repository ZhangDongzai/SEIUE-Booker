# 04 抓包与配置指南

> v1.1 起只需**一条 POST 请求**。接口路径与字段已实测确认，详见《05 实测接口与联调》。

## 1. 复制哪条请求

1. 浏览器打开 <https://chalk-c3.seiue.com/venues/venue-list> 并确认已登录。
2. 手动预约成功一次（选一个冷门时段，约完可以自己去取消）。
3. 按 `F12` 打开开发者工具 → `Network`（网络）标签 → 勾选 `Fetch/XHR`。
4. 在列表里找 **`orders`** 结尾、方法是 **POST** 的那条：

   ```
   order-venues/2953/orders        POST   200
   ```

   > ⚠️ 同名请求会有两条：一条 `OPTIONS`（浏览器预检），一条 `POST`（真正的提交）。
   > **选 POST 那条**；程序会拒绝 OPTIONS 并提示重选。

5. 右键该请求 → `Copy` → **`Copy as cURL (bash)`**。

## 2. 粘贴到哪里

设置页 →「① 一键导入（推荐）」→ 粘贴 → 「解析并生成配置」。

程序自动完成：

| 步骤 | 结果 |
| --- | --- |
| 提取身份 | `authorization`（Bearer JWT）、`x-role`、`x-school-id`、`x-reflection-id` 等 → 加密写入会话 |
| URL 占位符化 | `/order-venues/2953/orders` → `/order-venues/{{venue_order_id}}/orders` |
| 请求体占位符化 | `type` / `time_ranges` / `date_ranges` / `capacity` / `description` → 占位符，其余字段原样保留 |
| 去重 | 模板里不再保留 `Authorization` / `Cookie`，身份只由会话提供（换令牌不必改模板） |

随后跳到模板编辑页，可直接核对，一般不需要改动。

## 3. 手动配置（可选）

「模板 → 新建」里填：

| 字段 | 值 |
| --- | --- |
| 类型 | 下单 |
| 方法 | `POST` |
| URL | `https://api.seiue.com/scms/venue/order-venues/{{venue_order_id}}/orders` |
| 请求头 | `{"accept":"application/json, text/plain, */*","content-type":"application/json","origin":"https://chalk-c3.seiue.com","referer":"https://chalk-c3.seiue.com/"}` |

请求体：

```json
{
  "type": "{{order_type}}",
  "time_ranges": {{time_ranges}},
  "date_ranges": {{date_ranges}},
  "capacity": "{{capacity}}",
  "description": "{{description}}"
}
```

两处注意：

- `time_ranges` / `date_ranges` **不要加引号**，它们是裸 JSON 注入。
- `capacity` 加了引号也没关系，渲染时按数字类型输出 `2`（不是 `"2"`）。

## 4. 会话只导入，不手抄

不要把 `authorization` 的值复制进模板——令牌 24 小时过期，写死在模板里会静默失效。
「设置 → 手动导入」也支持只贴请求头文本：

```
authorization: Bearer xxxxx
x-role: student
x-school-id: 282
```

## 5. 联调顺序（建议）

1. 设置页粘贴 cURL → 看到「令牌剩余有效 N 小时 M 分」。
2. 点「同步场地」→ 看到 6 块羽毛球场地。
3. 新建任务：勾选 1–2 块场地、时段 `17:30`–`18:30`、人数 `2`、备注 `打球`。
4. 开「演练模式」→ 手动执行 → 确认场地/日期正确，且**没有发出 POST**。
5. 关闭演练 → 手动执行 → 在「记录 → 详情」比对请求体与 §3 是否一致。

## 6. 常见问题

| 问题 | 原因 / 处理 |
| --- | --- |
| 提示「这是预检请求」 | 复制到 OPTIONS 了，改选 POST 那条 |
| 执行记录 `HTTP 401` | 令牌过期，重新导入 |
| `HTTP 403 该操作超出了权限范围` | 少了 `x-school-id` / `x-role`，用一键导入重新抓一次 |
| `HTTP 409` 或带 message 的业务错误 | 时段被占 / 超出开放时间（工作日 16:35–18:30）/ 超出限额 |
| 执行成功但没有预约 | 场地 `need_approval = true`，需到「我的预约」审批 |
| 请求 `HTTP 0` | 网络或代理问题，在运行程序的终端里 `curl -I https://api.seiue.com` 排查 |
