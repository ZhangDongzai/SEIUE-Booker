# 05 数据与接口

## 1. 数据库

单文件 SQLite，WAL 模式，路径 `DATA_DIR/app.db`。所有读写都在 `app/store.py`。

### 1.1 `settings`（键值对）

| key | 内容 |
| --- | --- |
| `session_headers` | 导入的会话请求头（加密后存储） |
| `passport_cookie` | passport 域会话 Cookie（加密后存储） |
| `refresh_token` | refresh_token（加密后存储，界面已不提供入口） |
| `venues` | 最近一次同步的场地清单（JSON） |
| `venues_at` | 场地清单同步时间 |
| `last_check` | 上次会话自检结果（状态码、耗时、片段） |
| `token_refresh_state` | 上次续期结果（时间、是否成功、走哪条通道） |
| `check_url` | 自定义的会话自检地址 |

加密字段用 `app/crypto.py`（HMAC-CTR + Encrypt-then-MAC），密钥在 `data/secret.key`。

### 1.2 `templates`（请求模板）

| 字段 | 说明 |
| --- | --- |
| `kind` | `list`（查询，可选）或 `order`（下单，必需） |
| `method` / `url` | 方法与本址，URL 里可含 `{{venue_order_id}}` |
| `headers` | JSON 对象，值可含占位符 |
| `body` | 请求体原文，可含占位符 |
| `note` | 备注 |

首次启动只预置一份「场地清单」模板；**下单模板必须由「一键导入」从真实 cURL 生成**。

### 1.3 `tasks`（任务）

关键字段：

| 字段 | 说明 |
| --- | --- |
| `target_date` | 目标日期（`YYYY-MM-DD`），**调度的唯一依据** |
| `open_time` | 窗口开启日的触发时刻，默认 `00:00:30` |
| `venue_ids` | 场地 ID 白名单，逗号分隔，**顺序即尝试顺序** |
| `slot_start` / `slot_end` | 时段，如 `17:30` / `18:30` |
| `capacity` / `description` | 人数与备注 |
| `list_template_id` / `order_template_id` | 绑定的模板 |
| `max_attempts` / `interval_ms` | 轮次与间隔 |
| `prewarm_ms` | 提前多少毫秒预热（用于提前校时） |
| `dry_run` | 演练模式：只走流程不提交 |
| `enabled` | 是否排程；成功后程序会自动置 0 |

历史列（`day_offset`、`schedule_mode`、`once_at`、`map_*`）保留只为兼容旧库，
新逻辑不再读取；`day_offset` 仅在没有 `target_date` 时作为日期回退。

### 1.4 `runs` / `attempts`（执行记录）

```
runs 1 ──── n attempts
```

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `runs` | `trigger` | `schedule` / `manual` / `now` |
| | `planned_at` / `started_at` / `finished_at` | 计划、开始、结束 |
| | `status` | `running` / `success` / `failed` |
| | `message` | 一句人话结论 |
| | `resolved` | 解析出的候选场地、令牌状态等快照（JSON） |
| `attempts` | `seq` | 本次执行内的第几个请求 |
| | `venue_name` | 对应哪个候选场地 |
| | `request_headers` / `request_body` | 实际发出的报文 |
| | `http_status` / `duration_ms` / `ok` | 结果 |
| | `response_excerpt` | 响应片段（最多 8000 字） |

## 2. 占位符

模板里写 `{{name}}`，渲染时替换。**类型感知**：值为数字/对象时输出裸值，字符串按 JSON 转义。

### 2.1 日期与时间

| 占位符 | 示例 | 说明 |
| --- | --- | --- |
| `{{date}}` | `2026-10-21` | 目标日期 |
| `{{date_compact}}` | `20261021` | 紧凑格式 |
| `{{date_slash}}` | `2026/10/21` | 斜杠格式 |
| `{{date_cn}}` | `2026年10月21日` | 中文格式 |
| `{{weekday}}` / `{{weekday_cn}}` | `3` / `周三` | 星期 |
| `{{slot_start}}` / `{{slot_end}}` | `17:30` | 时分 |
| `{{slot_start_full}}` / `{{slot_end_full}}` | `17:30:00` | 时分秒 |
| `{{datetime_start}}` / `{{datetime_end}}` | `2026-10-21 17:30:00` | 日期+时间 |
| `{{date_ranges}}` | `{"start_at":"2026-10-21","end_at":"2026-10-21"}` | **裸 JSON** |
| `{{time_ranges}}` | `[{"start_at":"2026-10-21 17:30:00","end_at":"2026-10-21 18:30:00"}]` | **裸 JSON** |

### 2.2 业务字段

| 占位符 | 说明 |
| --- | --- |
| `{{order_type}}` | 下单类型，固定 `single_day` |
| `{{capacity}}` | 人数（数字） |
| `{{description}}` | 备注 |
| `{{venue_order_id}}` / `{{venue_id}}` | 当前候选场地 ID |
| `{{venue_name}}` | 场地名（如 `羽毛球场地12号`） |
| `{{venue_num}}` / `{{slot_id}}` | 候选补充信息（模板里用到时才填） |

### 2.3 工具字段

| 占位符 | 说明 |
| --- | --- |
| `{{ts}}` / `{{ts_ms}}` | 秒/毫秒时间戳 |
| `{{uuid}}` / `{{nonce}}` | 随机值，用于幂等键或防缓存 |
| `{{rerun}}` | 第几轮（从 1 开始） |
| `{{now}}` | 当前时间（ISO） |

### 2.4 写法注意

```jsonc
// 正确：裸写，输出数组/对象
"time_ranges": {{time_ranges}}

// 错误：会被转义成字符串
"time_ranges": "{{time_ranges}}"

// 数字也正确：输出 2 而不是 "2"
"capacity": "{{capacity}}"
```

## 3. 站点接口（2026-10 实测）

数据面是 `https://api.seiue.com`，前端壳是 `https://chalk-c3.seiue.com`。

### 3.1 鉴权

```
Authorization: Bearer <JWT>
x-role: student
x-school-id: 282
x-reflection-id: <学号对应的 reflection id>
```

JWT 有效期 **24 小时**（`exp - iat = 86400`），过期后所有业务接口返回 401。

### 3.2 场地清单

```
GET https://api.seiue.com/scms/venue/order-venues
```

返回数组，每项包含：

| 字段 | 说明 |
| --- | --- |
| `id` | 场地 ID（羽毛球为 2948–2953，对应 8 号–13 号场） |
| `name` | 名称 |
| `need_approval` | 是否需要审批（羽毛球 `true`） |
| `max_order_days` | 可提前预约天数（7） |
| `time_limit` | 单次时长上限（小时） |
| `open_time_ranges` | 开放时段，如工作日 `16:35–18:30` |

这个接口只给「场地」，**不含任何时段余量信息**。

### 3.3 提交预约

```
POST https://api.seiue.com/scms/venue/order-venues/{场地ID}/orders
Content-Type: application/json

{"type":"single_day",
 "time_ranges":[{"start_at":"2026-10-21 17:30:00","end_at":"2026-10-21 18:30:00"}],
 "date_ranges":{"start_at":"2026-10-21","end_at":"2026-10-21"},
 "capacity":2,"description":"打球"}
```

成功返回订单实体：

```json
{"id":60982,"approval_status":"initiated","duration":30,"venue_id":2952}
```

- `approval_status = initiated` 表示**已提交、待审批**，不是最终通过；
- `duration` 由服务端按起止时间计算，任意起止都接受（不必凑 15 分钟整数倍）；
- 时段冲突返回 **409**；
- 超出开放时段会被拒。

### 3.4 读回

| 接口 | 说明 |
| --- | --- |
| `GET /scms/venue/orders/{id}` | 单条订单详情 |
| `GET /scms/venue/my-orders` | 我的预约列表 |
| `GET /scms/venue/orders?venue_id=` | **403**（越权），不要当列表用 |

## 4. 令牌续期接口

### 4.1 passport 会话 Cookie（推荐）

```
POST https://passport.seiue.com/authorize
Content-Type: application/x-www-form-urlencoded
Cookie: PHPSESSID=xxxx

response_type=token&client_id=GpxvnjhVKt56qTmnPWH1sA
```

| 情况 | 结果 |
| --- | --- |
| 带有效 Cookie | `201`，响应体含 `access_token` / `expires_in` |
| 无 Cookie 或已失效 | `401 {"name":"Unauthorized","message":"Login required"}` |

响应头带 `Access-Control-Allow-Credentials: true`，所以站点前端能在浏览器里跨域调它。

### 4.2 refresh_token（兜底）

```
POST https://api.seiue.com/chalk/oauth/tokens
Content-Type: application/x-www-form-urlencoded

grant_type=refresh_token&refresh_token=<RT>&client_id=<app id>&client_secret=<app secret>
```

必须表单编码，发 JSON 会 400。站点 Web 端**不保存** RT，所以这个入口在界面上已不提供。

## 5. 错误对照

| 状态码 | 常见原因 | 程序行为 |
| --- | --- | --- |
| `401` | 令牌过期 / 未导入会话 | 中止本次执行，提示重新导入 |
| `403` | 越权访问（如按 venue_id 查订单列表） | 记为该请求失败 |
| `404` | 路径不对（如场地 ID 写错） | 记失败，继续下一块场地 |
| `409` | 该场地该时段已被占 | 换下一块场地 |
| `422` / `400` | 请求体字段不符合预期 | 记失败，提示看响应片段 |
| `5xx` | 站点异常 | 记失败，按轮次重试 |

站点业务错误通常在响应体里，形如：

```json
{"name":"blink\\...","message":"..."}
```

`_judge()` 会把 `name` 以 `blink\` 开头的响应当作失败，即使 HTTP 是 2xx。
